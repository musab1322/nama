# المرحلة 2: التصميم المعماري

**الهدف:** تحديد *كيف* نحقق المتطلبات المعتمدة، قبل كتابة الكود.

## الخطوات
1. مخطط السياق والحاويات (C4 مستوى 1 و2): المستخدمون، والمنصة، والأنظمة الخارجية.
2. نموذج البيانات: الكيانات والعلاقات وقواعد الصلاحيات (RLS) وسياسة الاحتفاظ بالبيانات.
3. مسارات العمل الرئيسية كمخططات تسلسل لكل حالة استخدام Must (التوليد، المعاينة، نشر الويب، النطاقات، بناء ورفع المتاجر، التحديث الفوري، الفوترة).
4. عقود الواجهات: كل endpoint بمدخلاته ومخرجاته ورموز أخطائه، وكل webhook وتوقيعه.
5. تقسيم الملفات والمكونات: شجرة المجلدات ومسؤولية كل وحدة وحدودها.
6. نموذج التهديدات (STRIDE مختصر) والأسرار وأين تُخزَّن.
7. سجلات القرارات المعمارية (`ADR-xxx`): السياق، والخيارات، والقرار، والعواقب.
8. مصفوفة التتبع: كل `FR`/`NFR` ← المكوّنات التي تحققه.
9. تقدير التكلفة التشغيلية لكل مستخدم ولكل تطبيق مولَّد.

## قواعد
- كل قرار له بديل مرفوض وسبب الرفض.
- لا مكوّن بلا متطلب يبرره، ولا متطلب بلا مكوّن.
- المخاطر التقنية الجديدة تُضاف لسجل المخاطر.
