# المرحلة 3: التنفيذ

**الهدف:** كود نظيف مطابق للتصميم المعتمد، لا أكثر ولا أقل.

## الخطوات
1. تقسيم التصميم إلى مهام صغيرة (`T-xxx`)، كل مهمة تشير إلى `FR`/`NFR` ومكوّن.
2. ترتيب المهام حسب التبعيات، وتنفيذها بالترتيب.
3. لكل مهمة: الكود + اختبارات الوحدة الخاصة بها + تحديث سجل التنفيذ.
4. أي انحراف عن التصميم يتوقف عنده العمل: يُكتب طلب تغيير ويُعتمد أولاً.

## معايير الكود
- TypeScript صارم، بلا `any` غير مبرر.
- التحقق من كل مدخل خارجي (zod) على حدود النظام.
- لا أسرار في الكود أو المستودع أو السجلات.
- رسائل الأخطاء للمستخدم مترجمة (عربي/إنجليزي) ولا تكشف تفاصيل داخلية.
- كل نص في الواجهة من ملف الترجمة، وكل تخطيط يدعم RTL.
- عمليات قاعدة البيانات عبر migrations فقط، ولا تُطبَّق على بيئة حية دون موافقة.
- commit لكل مهمة برسالة تذكر معرّفها.
