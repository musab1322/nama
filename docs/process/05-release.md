# المرحلة 5: النشر والصيانة

**الهدف:** إطلاق آمن قابل للتراجع، وتشغيل مستدام بعده.

## الخطوات
1. قائمة البيئات (development / staging / production) ومتغيرات كل بيئة (بلا قيم سرية).
2. خطوات النشر بالترتيب: migrations، ثم الخدمات، ثم العامل (worker)، ثم الواجهة، مع أمر التحقق بعد كل خطوة.
3. خطة التراجع لكل خطوة.
4. المراقبة والتنبيهات: الأخطاء، وفشل البناء، وطوابير المهام، والتكاليف.
5. النسخ الاحتياطي والاستعادة، واختبار الاستعادة مرة على الأقل.
6. التوثيق: دليل تشغيل (Runbook) للحوادث الشائعة، ودليل للمستخدم النهائي.
7. خطة الصيانة: تحديث التبعيات، ومتابعة تغييرات سياسات Apple وGoogle، وتجديد الشهادات والمفاتيح.
8. خارطة التطوير المستقبلي: ما أُجِّل من المتطلبات (Could/Won't) مرتباً.

## قواعد
- لا نشر للإنتاج إلا بموافقة صريحة لكل إطلاق.
- كل إطلاق له رقم إصدار وملاحظات إصدار تشير لمعرّفات المتطلبات.

## بوابة الخروج
- [ ] النشر على staging نجح وتم التحقق منه.
- [ ] خطة التراجع مجرَّبة.
- [ ] مصعب اعتمد الإطلاق.
